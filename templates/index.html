01 Import your browser history

No passwords needed

Upload Chrome’s History database, or BrowserHistory.json from Google Takeout. Optionally add Chrome’s Login Data database to identify sites with stored passwords. Maximum 256 MB combined. Unzip archives first.

Where do I find these Chrome files?

Open chrome://version in Chrome and locate Profile Path. Close Chrome completely, then copy History and optionally Login Data from that folder. Do not upload the entire profile, cookies, or a plaintext password CSV. The History file alone does not contain saved passwords.

History shows visited sites. The optional Login Data file adds stored-password associations. No usernames or password values are extracted; a stored entry does not prove that the password was used or stolen.
